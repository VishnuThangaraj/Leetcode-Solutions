## 📁 Repository Structure

Solutions are organized into modular range folders to keep the repository structured and scalable as more solutions are added:

```
Leetcode-Solutions/
└── <range_folder>/
    └── <problem_id> - <Problem Title>.<ext>
```

- **Range Folders**: Group problems into convenient batches (e.g., `3851-3900/`, `0151-0200/`).
- **File Naming**: `<problem_id> - <Problem Title>.<ext>` containing the solution along with problem links and notes.
